# DudeShape — лендинг мебельного магазина

Адаптивный лендинг по макету из Figma. Вёрстка, интерактивные модули на чистом JavaScript и сборка на webpack с автоматическим деплоем.

**Сайт:** https://viktorovvik.github.io/dudeshape/

## Стек

- HTML, SCSS, JavaScript (ES-модули, классы)
- webpack 5: html-loader, sass-loader, MiniCssExtractPlugin, copy-webpack-plugin
- Swiper для слайдера
- GitHub Actions + GitHub Pages для сборки и деплоя

## Что реализовано

- **Мобильное меню:** бургер с `aria-expanded`, закрытие по `Escape` с возвратом фокуса, ловушка фокуса внутри открытого меню.
- **Слайдер популярных товаров** на Swiper со своими кнопками и брейкпоинтами.
- **Избранное:** сохраняется в `localStorage` через отдельный модуль-хранилище, синхронизирует кнопки одного товара, счётчик в шапке.
- **Табы по стандарту WAI-ARIA:** переключение мышью и с клавиатуры (стрелки по кругу, Home/End, Cmd + стрелки на macOS), roving `tabindex`.
- **Смена фото мебели:** данные загружаются из JSON через `fetch`, выбранная кнопка отмечается `aria-pressed`, фото плавно проявляется.
- **Форма подписки:** встроенная валидация браузера, состояния отправки, имитация запроса с успехом и ошибкой, уведомление с `role="status"`, которое скрывается само или по крестику.
- **Аккордеон в footer** на `<details>` / `<summary>`: на телефоне списки свёрнуты, на широком экране открыты, ширина отслеживается через `matchMedia`; плавное раскрытие с появлением пунктов по очереди.
- **Адаптив** от 320px: макет был только для десктопа, мобильные раскладки продуманы самостоятельно.

## Подход

- **Доступность:** семантическая разметка, визуально скрытые подписи, `aria`-атрибуты, видимый фокус, управление с клавиатуры.
- **BEM:** переиспользуемые блоки (`subscribe-form`, `toast`, `logo`, `social`) подключаются в разные места через миксы и модификаторы.
- **JavaScript:** каждый модуль — класс с коллекцией, элементы выбираются только через `data-js-*` атрибуты, состояние хранится в `state`, экран обновляет `render()`, у каждого модуля есть `destroy()`.
- **Иконки:** SVG-спрайт, цвет через `currentColor`, второй цвет иконок соцсетей через CSS-переменную.
- **Сборка:** хеши в именах JS, CSS и картинок для корректного обновления кэша, статика из `public` копируется как есть.

## Запуск

```bash
npm install
npm run dev      # dev-сервер на http://localhost:3000
npm run build    # продакшен-сборка в папку dist
```

## Структура

```
src/
  index.html
  index.js            — точка входа, подключает модули
  modules/            — JS-модули (Tabs, Furniture, Newsletter, ...)
  utils/storage.js    — работа с localStorage
  styles/             — SCSS: helpers, base, components
  assets/             — шрифты, изображения, SVG-спрайт
public/               — копируется в сборку без изменений
  data/furniture.json
  images/furniture/
.github/workflows/    — сборка и деплой на GitHub Pages
```
